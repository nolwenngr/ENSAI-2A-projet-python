# Analyse de la fréquentation des musées en France

Par Eulalie Amigo & Nolwenn Gorgé, 2026.

# Installation des dépendances nécessaires
Installez les dépendances nécessaires listées dans le fichier requirements.txt avec la commande `pip install -r requirements.txt`.

# Structure du projet
Le projet s'articule en trois parties. La première partie importe les bases de données, unifie des noms de variables, analyse la non réponse totale et partielle et créer les variables utiles aux parties suivantes. La seconde partie réalise quelque analyses descriptives sur nos données notamment avec de la cartographie. Enfin, la troisième partie réalise un clustering.
